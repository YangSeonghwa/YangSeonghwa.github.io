2. ESASky (실제 망원경 사진 확대)

  • 유럽우주국(ESA)에서 제공하는 실제 전천 관측 지도
  • 어두운 성운(마귀할멈·측상어 성운)도 고해상도 DSS2 컬러 사진으로 선명하게 관측 가능

ESASky 열기 ↗

Slide 3 / 9관측 ① · 방출성운

🌙 [관측 1] 초승달 성운 (Crescent Nebula, NGC 6888)

  • 종류: 방출성운 (발광성운)
  • 별자리 / 거리: 백조자리 / 약 5,000 광년
  • 왜 초승달 모양일까? 중심의 매우 뜨거운 울프-레이에 별(WR 136)이 내뿜는 강한 항성풍이 주변 가스를 밀어내어 껍질 모양을 만듭니다.
  • 왜 붉게 빛날까? 중심 별의 강한 자외선에 가열된 수소 가스가 스스로 붉은빛을 방출하기 때문입니다.

🌟 Stellarium Web (C27) ↗ 🛰️ ESASky 실제 사진 ↗

🧙 [관측 2] 마귀할멈 성운 (Witch Head Nebula, IC 2118)

  • 종류: 반사성운
  • 별자리 / 거리: 에리다누스자리 / 약 900~1,000 광년
  • 별명 유래: 매부리코와 뾰족한 턱을 가진 마귀할멈의 옆모습을 닮았습니다.
  • 왜 푸르게 빛날까? 성운 옆에 있는 밝은 청백색 별 리겔(오리온자리 β별)의 빛을 성간 먼지가 반사·산란시키는데, 파장이 짧은 푸른빛이 더 잘 산란되기 때문입니다.

🔭 바로 관측하기

오리온자리 리겔 바로 옆에서 마귀할멈 옆모습을 찾아보세요!

🌟 Stellarium Web (IC 2118) ↗ 🛰️ ESASky 실제 사진 ↗
📌 교사용 노트: 방출성운(스스로 빛냄, 붉은색)과 반사성운(주변 별빛 반사·산란, 푸른색)을 대비시켜 설명하면 학생들이 매우 잘 이해합니다.

🦈 [관측 3] 측상어 성운 / 상어 성운 (Dark Shark Nebula, LDN 1235)

  • 종류: 암흑성운
  • 별자리 / 거리: 세페우스자리 / 약 650 광년
  • 모습 특징: 거대한 성간 먼지 구름이 뒤쪽에서 오는 별빛을 가로막아, 어두운 상어가 우주 속을 헤엄치는 듯한 실루엣을 만듭니다.
  • 관측 팁: 스스로 빛을 내지 않으므로 밝은 별 배경과 대조되는 검고 어두운 틈에 집중해 보세요.

🐝 [관측 4] M44 프레세페 성단 (벌집 성단, Beehive Cluster)

  • 종류: 산개성단
  • 별자리 / 거리: 게자리 / 약 600 광년 (약 3.1등급)

  • 우리은하 위치: 성간 물질이 풍부한 은하면(나선팔) 부근에 주로 분포합니다.

🌹 [관측 5] M5 구상성단 (Rose Cluster, NGC 5904)

  • 종류: 구상성단
  • 별자리 / 거리: 뱀자리 / 약 24,500 광년 (약 5.9등급)
  • 특징: 수십만 개의 나이가 많은 늙은 별들이 중력으로 인해 공 모양으로 매우 빽빽하게 모여 있습니다.
  • 색깔과 분포: 붉은색·노란색 별이 많아 전체적으로 따뜻한 금빛/붉은빛을 띠며, 은하 중심부와 헤일로에 분포합니다.

💡 5대 천체 관측 개념 확인 퀴즈 (5문항)

점수: 0 / 5
Q1. 백조자리에 있는 '초승달 성운(NGC 6888)'이 붉게 빛나는 까닭으로 옳은 것은?
정답: ②. 초승달 성운은 주변 고온 별의 에너지를 받은 수소 가스가 스스로 붉은빛을 내는 방출성운입니다.
Q2. '마귀할멈 성운(IC 2118)'이 푸른색으로 관측되는 이유와 성운의 종류는?
정답: ③. 마귀할멈 성운은 오리온자리 리겔의 빛을 성간 먼지가 반사·산란시켜 푸르게 보이는 반사성운입니다.
Q3. 세페우스자리의 '측상어 성운(상어 성운, LDN 1235)'이 우주 공간에서 검은 상어 실루엣처럼 보이는 이유는?
정답: ①. 암흑성운은 두꺼운 성간 먼지가 뒤쪽의 별빛이나 성운의 빛을 흡수·차단하여 어둡게 보입니다.
Q4. 게자리의 'M44(프레세페 성단)'에 대한 설명으로 옳은 것은?
