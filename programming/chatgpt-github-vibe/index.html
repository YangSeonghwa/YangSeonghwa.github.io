개념

바이브 코딩이란?

🗣 말하기

만들고 싶은 모습을 우리말로 자세히 설명한다.

🤖 만들기

AI가 HTML, CSS, JavaScript 코드를 써 준다.

👀 확인하기

결과를 직접 보고 마음에 안 드는 점을 다시 말한다.

나는 코드를 한 줄씩 치는 사람이 아니라, AI에게 방향을 알려 주는 지휘자예요.

AI가 만든 결과는 틀릴 수 있어요. 반드시 내 눈으로 확인하고, 모르는 부분은 설명해 달라고 요청해요.

코딩 지식이 없어도 시작할 수 있다는 점을 강조하되, 결과를 검증하는 습관이 핵심 역량임을 짚어 주세요.

내 홈페이지

ChatGPT와 GitHub 저장소를 연결하면, ChatGPT가 내 저장소의 파일을 참고해 더 알맞은 코드를 만들어 줄 수 있어요.

연결로 할 수 있는 일(읽기·참고)과 학생이 직접 하는 일(복사·커밋)을 구분해서 설명해 주세요.
1단계

GitHub 저장소 만들고 Pages 켜기

순서할 일
1GitHub에 로그인 → 오른쪽 위 + → New repository
2저장소 이름: 내아이디.github.io (아이디와 똑같이)
3Public 선택, Add a README file 체크 → Create repository
4Settings → Pages → Source: Deploy from a branch → Branch: main, 폴더 / (root) → Save
5입구 파일은 저장소 맨 위 폴더의 index.html

화면 글자는 한국어/영어로 다르게 보일 수 있어요. 참고: GitHub Pages 공식 문서 (docs.github.com, pages.github.com)

Pages는 branch의 최상위 폴더에서 index.html을 찾아 첫 화면으로 씁니다. 저장소 이름이 사용자이름.github.io여야 https://사용자이름.github.io 주소가 됩니다.
2단계

ChatGPT에 GitHub 연결하기

  1. ChatGPT 입력창 옆의 + (또는 클립) 메뉴에서 GitHub 연결을 찾아요.
  2. GitHub 로그인 화면에서 허용(Authorize)을 눌러요.
  3. ChatGPT가 볼 수 있는 저장소를 직접 고릅니다 (다음 쪽 참고).
  4. 새 채팅에서 GitHub를 켜고 「내 저장소 목록에서 내아이디.github.io가 보이니?」라고 물어 확인해요.

메뉴 이름과 위치는 업데이트와 요금제에 따라 달라질 수 있어요. 예전에 「플러그인」이라고 부르던 기능은 지금은 주로 「앱/커넥터」라는 이름으로 보여요.

수업 직전에 교사 계정으로 실제 화면을 한 번 확인하고 캡처를 보조 자료로 준비하세요. 연결 기능이 보이지 않는 학생은 2단계를 건너뛰고 저장소 내용을 붙여 넣어 대화하는 방법으로 진행해도 3~5단계는 그대로 할 수 있습니다.
안전하게

연결 권한은 꼭 필요한 만큼만

✅ 이렇게

  • 접근 저장소는 선택한 저장소만(Only select repositories)
  • 이 수업용 저장소 하나만 고르기
  • 수업이 끝나면 GitHub 설정의 Applications에서 연결 해제

⚠ 이렇게는 안 돼요

  • 모든 저장소(All repositories) 허용
  • 비밀번호·키·학생 정보가 든 저장소를 연결
  • 모르는 사이트에 GitHub 로그인

모든 저장소를 허용하면 계정이 접근할 수 있는 공개·비공개 저장소가 모두 범위에 들어갈 수 있어서, 선택한 저장소만 허용하라는 안내가 있습니다.

이 쪽은 시간을 충분히 쓰세요. 학생이 허용 화면을 대충 넘기지 않도록, 저장소 선택 화면에서 한 번 멈추고 모둠별로 확인하게 합니다.
3단계

좋은 설명(프롬프트) 만들기

누가 볼까 + 무엇을 담을까 + 어떤 분위기 + 지켜야 할 조건 을 함께 말해요.

나는 중학교 과학 시간에 만든 발표를 소개하는 홈페이지가 필요해. - 보는 사람: 친구들과 선생님 - 구성: 제목 영역, 내 소개, 좋아하는 과학 주제 카드 3개, 응원 한마디 영역 - 분위기: 밝은 파스텔 색, 둥근 모서리 - 조건: index.html 한 파일, 외부 라이브러리 없이, 휴대폰에서도 잘 보이게 - 마지막에 내가 글자를 바꿀 수 있는 부분을 알려 줘.
학생에게 먼저 자기 설명을 써 보게 한 뒤, 이 예시와 견주어 빠진 항목을 찾게 하면 좋습니다.
4단계

한 번에 하나씩 고쳐 달라고 해요

이럴 때이렇게 말해요
글자가 작아요「본문 글자를 지금보다 1.3배 크게 해 줘」
색이 마음에 안 들어요「배경은 연한 하늘색, 제목은 진한 남색으로 바꿔 줘」
휴대폰에서 깨져요「폭 360px 휴대폰 화면에서도 가로로 밀리지 않게 해 줘」
코드를 모르겠어요「이 부분이 무슨 일을 하는지 중학생에게 설명해 줘」

확인 체크: 휴대폰에서도 보이나요? 글자가 읽기 쉬운가요? 링크가 눌리나요? 내 정보가 너무 많이 드러나지 않나요?

여러 가지를 한꺼번에 요청하면 무엇이 바뀌었는지 알기 어렵습니다. 한 번에 하나, 바뀐 것 확인, 다음 요청의 리듬을 강조하세요.
5단계

GitHub에 저장하고 공개하기

  1. ChatGPT가 준 코드를 전체 복사해요 (일부만 복사하면 화면이 깨져요).
  2. 저장소에서 Add file → Create new file (이미 있으면 index.html을 열고 연필 아이콘으로 편집)
  3. 파일 이름을 index.html로 쓰고 코드를 붙여 넣어요.
  4. Commit changes → 메시지(예: 첫 홈페이지 만들기) → Commit
  5. 1~2분 뒤 https://내아이디.github.io 를 열고 새로고침(Ctrl+F5)해요.

이 수업에서는 학생이 직접 커밋하는 방법을 기본으로 해요. 무엇이 바뀌는지 눈으로 확인하는 연습이에요.

연결 기능으로 ChatGPT가 저장소에 직접 쓸 수 있는지는 계정과 시기에 따라 다릅니다. 가능하더라도 변경 내용을 학생이 확인하고 승인하는 흐름을 지키게 하세요.
