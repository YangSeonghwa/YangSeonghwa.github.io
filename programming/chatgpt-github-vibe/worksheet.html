꼭 기억해요. GitHub 연결 도구마다 권한이 달라요. 쓰기 기능이 있는 연결 도구라면 AI가 파일을 직접 수정하고 커밋할 수 있습니다. 읽기 전용 연결이면 직접 저장할 수 없으므로 교사 시연을 이용합니다. 공개되는 홈페이지와 개인정보는 반드시 확인해요. 저장소 이름은 GitHub 아이디와 같은 아이디.github.io로 만들면 주소가 짧아집니다. 단, 아이디가 실명·학교명 등을 드러내지 않는지 먼저 확인해요. 만 13세 미만은 개인 ChatGPT·GitHub 계정으로 활동하지 않고 교사 시연과 모둠 활동으로 참여합니다. 13~17세도 보호자 동의와 학교 지침을 확인합니다.
