핵심 개념 완벽 이해 장바구니 → 세이브 → 우주 발사

Git 삼총사: 담기(Add) · 세이브(Commit) · 발사(Push)

개발자들이 매일 쓰는 git 명령어 3가지는 사실 게임 세이브와 우주 정거장 전송과 똑같습니다!

🛒
1단계: 장바구니 담기 (Add)
git add .

내 방 책상(컴퓨터)에서 새로 만들거나 고친 파일들을 "이것들을 저장할 거야!" 하고 포털 장바구니에 모두 골라 담는 단계예요.

💡 뒤에 붙은 점(.)은 "폴더 안의 모든 파일"이라는 뜻!

🎮💾
2단계: 게임 세이브 (Commit)
git commit -m "메시지"

보스전을 앞두고 세이브 포인트에 도장을 쾅 찍는 거예요! 나중에 코드가 망가져도 언제든 이 세이브 지점으로 되돌아갈 수 있어요.

💡 -m 뒤에는 "무엇을 만들었는지" 메모를 남겨요!

🚀🛰️
3단계: 우주 정거장 발사 (Push)
git push origin main

내 컴퓨터에만 있던 세이브 파일을 인터넷 우주 정거장(GitHub)으로 "슝~" 밀어 올려서(Push) 전 세계 친구들이 접속하게 해요!

💡 Push를 해야 인터넷 주소에 진짜 반영돼요!

❓ 자주 헷갈리는 질문: "선생님, VS Code에서 Ctrl + S(파일 저장)를 눌렀는데 왜 인터넷 주소는 안 바뀌나요?"
👉 Ctrl + S는 내 컴퓨터 공책에만 적은 거예요! 반드시 Add(담기) → Commit(세이브 도장) → Push(우주 발사) 3단계를 거쳐야 인터넷에 올라갑니다.
교사 메모: 이 슬라이드의 3단계(🛒 장바구니 → 🎮 세이브 포인트 → 🚀 우주 정거장) 비유를 칠판에 적어두면 실습 내내 학생들이 명령어 순서를 절대 잊어버리지 않습니다.
실습 1단계 (준비) VS Code & GitHub CLI 설치

VS Code 터미널 열기 & GitHub CLI(gh) 설치하기

GitHub CLI(gh)는 마우스로 복잡하게 웹사이트를 클릭하지 않고, 터미널 명령어로 GitHub 로그인과 배포를 한 방에 처리해 주는 마법 리모컨입니다.

1VS Code에서 터미널 열기

  • VS Code 실행 후 상단 메뉴 [터미널(Terminal)] → [새 터미널(New Terminal)] 클릭!
  • 단축키: Ctrl + ` (숫자 1 왼쪽의 물결표 키)
  • 아래쪽에 검은색(또는 흰색) 명령어 입력창이 나타나면 성공!

2설치 여부 확인하기

터미널에 아래 명령어를 치고 Enter를 눌러 보세요.

gh --version

gh version 2.x.x...라고 숫자가 나오면 이미 설치 완료! 오류가 나면 아래 표대로 설치하세요.

운영체제 (OS) 초간단 설치 방법 (터미널에 복사해서 붙여넣기) 설치 후 필수 팁!
🪟 Windows (윈도우) winget install --id GitHub.cli 입력 후 엔터!
(또는 인터넷에서 cli.github.com 접속 후 설치 파일 다운로드)		 설치가 끝나면 VS Code를 한 번 껐다가 다시 켜야(재시작) 터미널이 gh 명령어를 인식합니다! 🔄
🍎 macOS (맥북) brew install gh 입력 후 엔터!
교사 메모: 학교 컴퓨터실 PC에 Git과 GitHub CLI가 미리 설치되어 있다면 `gh --version` 확인만 하고 바로 다음 슬라이드(로그인)로 넘어가세요. 설치 직후 `'gh'은(는) 내부 또는 외부 명령... 이 아닙니다` 오류가 뜨면 VS Code를 껐다 켜도록 안내하세요.

실습 3단계 (세상에 공개!) Commit & Push 실전

터미널 명령어로 세이브(Commit)하고 우주로 발사(Push)하기 🚀

내 컴퓨터에서 완성한 index.html을 이제 인터넷 우주 정거장(GitHub)으로 쏘아 올릴 시간입니다!

🅰️ 이미 연결된 저장소 폴더일 때 (기본 3단 콤보)

# 1. 장바구니에 모든 파일 담기
git add .

# 2. 게임 세이브 포인트 도장 찍기
git commit -m "나만의 첫 번째 바이브 코딩 웹사이트 완성!"

# 3. GitHub 우주 정거장으로 발사!
git push origin main

🅱️ 새 폴더에서 처음 저장소까지 한 방에 만들 때 (gh 마법)

# Git 시작 + 담기 + 세이브
git init
git branch -M main
git add .
git commit -m "첫 웹사이트 탄생!"

# GitHub에 공개 저장소 만들고 바로 푸시까지 한 번에!
gh repo create my-vibe-web --public --source=. --remote=origin --push

🌐 마지막 스위치 켜기: GitHub Pages로 진짜 인터넷 주소 만들기

  1. GitHub 내 저장소 페이지 상단의 ⚙️ [Settings(설정)] 클릭 → 왼쪽 메뉴에서 [Pages] 클릭!
  2. Branch(브랜치) 항목에서 None을 main으로 바꾸고 옆의 [Save] 버튼 클릭!
  3. 약 1~2분 뒤 새로고침하면 상단에 https://내아이디.github.io/저장소이름/ 주소가 짠! 하고 나타납니다 🎉
교사 메모: `git commit` 실행 시 `Author identity unknown` 메시지가 뜨는 학생이 있다면 다음 슬라이드의 응급처치 명령어를 보여주시면 10초 만에 해결됩니다!
