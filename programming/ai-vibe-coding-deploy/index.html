AI가 문제 풀이와 반복 업무를 대신하는 시대에 가장 값비싼 가치는 무엇일까요? 바로 "내가 무엇을 미치도록 좋아하는지 알고, 내 안에 넘치는 즐거움을 매력적인 결과물로 만들어 다른 사람과 공유하는 힘"입니다. 여러분의 덕질과 취미가 곧 미래의 진짜 직업이 됩니다!

친구 기분별 최애 K-POP 추천기, 클릭하면 색이 바뀌는 가상 응원봉, 콘서트 응원법 타이밍 연습기, 컴백 디데이 타이머!

🚀 미래 직업: 뮤직 테크 기획자 · 글로벌 엔터 프로듀서

⚽ 4. 스포츠 (축구·야구·농구·풋살)

우리 반 점심시간 풋살 리그 대진표·승점 계산기, 최애 구단 선수 스탯 비교 차트, 나에게 딱 맞는 축구 포지션 성향 테스트!

🚀 미래 직업: 스포츠 데이터 애널리스트 · 매치 디렉터

🔬 5. 우주·과학·공룡·미스터리

슬라이더로 조절하는 별의 표면온도와 색깔 실험실, 블랙홀 크기 비교 사전, 친구들과 대결하는 과학 상식 방탈출 퀴즈!

🚀 미래 직업: 과학 커뮤니케이터 · 에듀테크 창업가

🍰 6. 일상 취미·패션·베이킹·운동

나만의 베이킹 레시피 계량 계산기, 퍼스널 컬러 코디 추천기, 급식 메뉴 꿀조합 도감, 홈트레이닝 루틴 타이머 웹앱!

핵심 가치 2 · 왜 지금(중학교 시기)인가? 동일한 출발선 × 전두엽 폭발적 발달

어른들과 완전히 동일한 출발선, 중학생의 뇌가 압도적으로 유리합니다 🧠⚡

과거에는 어른들이 수년간 영어 문법을 외워야만 프로그램을 만들 수 있었습니다. 하지만 AI 바이브 코딩 시대에는 어른 개발자들과 여러분이 완전히 똑같은 출발선에 서 있으며, 오히려 중학생인 여러분이 압도적으로 빠르게 체화할 수 있습니다!

🏁 강점 1: 어른들과 100% 동일한 출발선!

  • 연습용 장난감이 아닌 진짜 프로의 도구: 오늘 우리가 쓰는 VS Code + GitHub Copilot + GitHub CLI는 실리콘밸리와 판교의 성인 개발자들이 지금 현업에서 쓰는 도구와 100% 똑같습니다.
  • 모두에게 처음 열린 신대륙: AI와 자연어로 대화하며 소프트웨어를 설계·배포하는 방식은 10년 차 어른 개발자들에게도 지금 막 시작된 완전히 새로운 출발선입니다.
  • 학력·경력 장벽의 소멸: 복잡한 문법 암기 장벽이 사라졌기 때문에, 중학생도 오늘 당장 어른들과 동등한 수준의 웹 서비스를 세상에 내놓을 수 있습니다.

🧠 강점 2: 전두엽이 폭발적으로 발달하는 중학교 시기!

  • 뇌과학적 골든타임(만 12~15세): 중학교 시기는 인간의 뇌에서 고차원적 사고와 창의적 설계를 담당하는 전두엽(Prefrontal Cortex)이 인생에서 가장 폭발적으로 재구조화·발달하는 시기입니다.
  • 바이브 코딩 = 전두엽 지휘 능력: AI 시대의 코딩은 타자 치기가 아니라 "무엇을 만들지 상상하고, 전체 흐름을 기획하며, AI에게 핵심을 질문·지휘하는 전두엽의 힘"입니다.
  • 압도적으로 빠른 체화(Internalization): 옛날 방식에 굳어진 어른들은 기존 습관을 버리느라 애를 먹지만, 전두엽이 유연하게 뻗어나가는 중학생 때 배우면 마치 모국어나 자전거 타기처럼 직관적이고 압도적으로 빠르게 내 것으로 체화할 수 있습니다!
비교 항목 과거의 코딩 교육 (문법 암기 시대) 현재의 AI 바이브 코딩 (여러분과 어른의 대결!)
출발선 위치 어른들이 수년 앞서 있음 (영어 명령어·복잡한 문법 암기 필수) 어른과 중학생이 완전히 동일한 출발선! (자연어 지휘 능력으로 승부)
중학생(전두엽 발달기)의 유리함 오타 하나에 막혀 전두엽의 상상력을 펼치기 전에 포기함 😢 폭발적으로 발달하는 전두엽의 상상력·기획력이 AI와 결합해 성인보다 훨씬 유연하고 빠르게 체화됨 🚀
교사 메모: 뇌과학적으로 중학교 시기는 전두엽의 시냅스 가지치기와 재구조화가 폭발적으로 일어나 추상적 기획력·메타인지가 급성장하는 시기임을 설명해 주세요. 이때 AI라는 증폭기를 만나면 어른들보다 훨씬 빠르게 '창작의 감각'을 체화할 수 있습니다.
핵심 가치 3 · 작업 방식의 혁명 간접 방식(다운로드/업로드) vs 실시간 로컬 초고속 루프

기존 ChatGPT 플러그인 방식 vs 내 컴퓨터 로컬 VS Code 초고속 루프 ⚡

"그냥 ChatGPT 웹사이트에서 코드 짜달라고 하면 안 되나요?" — 파일을 다운로드·업로드하던 기존의 간접 방식과, 내 컴퓨터 로컬 VS Code에서 Copilot과 실시간 대화하며 즉시 결과를 보고 피드백하는 초고속 루프는 하늘과 땅 차이입니다!

🐢 기존 ChatGPT 웹 · 플러그인 방식 (간접 방식)

  • 번거로운 다운로드 & 업로드의 무한 반복: ChatGPT 웹에서 만든 파일을 내 컴퓨터로 다운로드하고, 수정할 때마다 다시 웹창에 파일을 업로드(또는 코드 전체 복사·붙여넣기)해야 하는 간접 방식입니다.
  • 맥이 끊기는 느린 피드백: "버튼 색깔 하나 바꾸기"를 하려 해도 [웹 질문 → 코드 생성 대기 → 파일 다운로드 → 폴더 이동 → 열기] 과정을 거치며 1~2분씩 흐름이 끊깁니다.
  • 파일 관리와 배포의 단절: 다운로드 폴더에 index (1).html, index (2).html이 쌓여 헷갈리고, GitHub 배포와도 연결되지 않습니다.

⚡ 내 컴퓨터 로컬 VS Code + Copilot (초고속 루프)

  • 다운로드·업로드 ZERO(0회) 직접 방식: 내 컴퓨터(로컬) 폴더에 있는 실제 파일을 VS Code Copilot이 직접 읽고 그 자리에서 즉시 수정합니다.
  • 실시간 대화 → 즉시 확인 → 즉시 피드백의 초고속 루프: Copilot과 실시간으로 대화하며 코드가 바뀌는 즉시 내 컴퓨터 브라우저에서 1초 만에 결과를 눈으로 보고 바로 다음 피드백을 던집니다!
  • 설치부터 GitHub 배포까지 원스톱: 코딩이 끝나면 창을 옮길 필요 없이 같은 VS Code 안에서 Copilot에게 자연어로 명령해 즉시 전 세계에 배포(Push)합니다.

핵심 가치 4 · 100% 자연어 지휘 터미널 명령어 암기 ZERO!

터미널 명령어를 직접 타이핑하지 마세요!
설치 · 로그인 · 커밋 · 푸시까지 모두 자연어로 명령합니다 🗣️✨

많은 사람들이 검은색 터미널 창에 영어로 된 명령어를 직접 타이핑하다가 오타가 나서 포기합니다. 오늘 수업에서는 웹사이트 코딩뿐만 아니라 프로그램 설치, 로그인, 커밋(세이브), 푸시(우주 발사)까지 전부 VS Code Copilot에게 우리말(자연어)로 명령하여 진행합니다!

❌ 기존 방식: 터미널에 명령어 직접 타이핑

  • winget install --id GitHub.cli 같은 대소문자·띄어쓰기를 직접 치다가 오타 발생 😢
  • git commit -m "...", gh repo create ... --source=. --push 등 복잡한 옵션을 외워야 함
  • 에러 메시지가 영어로 뜨면 무슨 뜻인지 몰라 손들고 선생님을 기다려야 함

⭕️ 우리의 방식: Copilot에게 자연어로 명령!

  • VS Code Copilot Chat(에이전트) 창에 친구에게 말하듯 우리말(자연어)로 원하는 작업을 지시!
  • Copilot이 내 컴퓨터 환경에 딱 맞는 터미널 명령어를 스스로 작성해 제안하거나 실행해 줌
  • 우리는 Copilot이 띄워준 Run in Terminal(터미널에서 실행) 또는 Continue(계속) 버튼만 클릭하면 끝! 🎬

교사 메모: 학생들에게 "오늘 검은 터미널 창에 영어를 직접 외워서 치지 않아도 됩니다! Copilot 채팅창에 우리말로 시키고 실행 버튼만 누르세요"라고 안내하면 학생들의 두려움이 완전히 사라집니다.
핵심 개념 완벽 이해 장바구니(Add) → 세이브(Commit) → 우주 발사(Push)

Copilot에게 시키기 전에 뜻만 알자! Git 삼총사 비유 🎮🚀

명령어를 외워서 직접 타이핑할 필요는 없지만, 내가 Copilot에게 무엇을 시키는지 개념을 알면 진짜 감독님이 될 수 있어요! 개발자들의 3단계는 게임 세이브와 우주 정거장 전송과 똑같습니다.

🛒
1단계: 장바구니 담기 (Add)
내부 동작: git add .

내 방 책상(컴퓨터)에서 새로 만들거나 고친 파일들을 "이 파일들을 저장할 거야!" 하고 장바구니에 모두 골라 담는 단계예요.

🗣️ 자연어: "수정한 파일들 전부 스테이징(add) 해줘"
🎮💾
2단계: 게임 세이브 (Commit)
내부 동작: git commit -m "메모"

보스전을 앞두고 세이브 포인트에 도장을 쾅 찍는 거예요! 나중에 코드가 망가져도 언제든 이 세이브 지점으로 되돌아갈 수 있어요.

🗣️ 자연어: "'첫 디자인 완성'이라고 커밋(세이브) 해줘"
🚀🛰️
3단계: 우주 정거장 발사 (Push)
내부 동작: git push

내 컴퓨터에만 있던 세이브 파일을 인터넷 우주 정거장(GitHub)으로 "슝~" 밀어 올려서(Push) 전 세계 친구들이 접속하게 해요!

🗣️ 자연어: "내 깃허브 저장소로 푸시(발사) 해줘"
❓ 자주 헷갈리는 질문: "선생님, VS Code에서 Ctrl + S(파일 저장)를 눌렀는데 왜 인터넷 주소는 안 바뀌나요?"
👉 Ctrl + S는 내 컴퓨터 공책에만 적은 거예요! Copilot에게 "방금 고친 내용을 커밋하고 깃허브에 푸시해줘!"라고 한 마디만 명령하면 Add(담기) → Commit(세이브) → Push(우주 발사) 3단계를 한꺼번에 처리해 줍니다!
교사 메모: 개념은 3단계(🛒 장바구니 → 🎮 세이브 포인트 → 🚀 우주 정거장)로 이해하되, 실제 실행은 Copilot에게 "커밋하고 푸시해줘"라고 자연어로 한 번에 지시하면 된다는 점을 연결해 주세요.
실습 1단계 (준비 · 설치 & 로그인) 터미널 직접 타이핑 NO! 자연어로 명령하기

Copilot에게 자연어로 GitHub CLI 설치 & 로그인 명령하기 🤖🔑

터미널 명령어를 직접 찾거나 타이핑하지 마세요! VS Code Copilot Chat(Ctrl+Alt+I) 창을 열고 아래 파란색 자연어 명령을 복사해서 붙여넣으면, Copilot이 설치부터 로그인까지 알아서 실행해 줍니다.

1 자연어로 '설치 확인 및 자동 설치' 명령하기

Copilot 채팅창에 아래 문장을 그대로 복사해 보내고, Copilot이 제안하는 [Run in Terminal (터미널에서 실행)] 버튼을 클릭하세요!

내 컴퓨터에 Git과 GitHub CLI(gh)가 설치되어 있는지 터미널에서 확인해줘. 만약 설치되어 있지 않다면 내 컴퓨터 운영체제(Windows winget 또는 Mac brew)에 맞는 명령어로 지금 바로 설치를 진행해줘!

💡 참고(Copilot이 대신 실행해 주는 명령어): gh --version 확인 후 미설치 시 Windows는 winget install --id GitHub.cli, Mac은 brew install gh를 자동 실행합니다. (새로 설치했다면 VS Code를 한 번 껐다 켜주세요! 🔄)

2 자연어로 'GitHub 웹 브라우저 로그인' 명령하기

설치가 확인되면, 다시 Copilot 채팅창에 아래 자연어 명령을 보내 로그인을 시작하세요!

GitHub CLI(gh)를 사용해서 내 GitHub.com 계정에 HTTPS 프로토콜과 웹 브라우저 방식으로 로그인할 수 있게 터미널 명령어를 실행해줘!

💡 참고(Copilot이 대신 실행해 주는 명령어): gh auth login --hostname github.com --git-protocol https --web (복잡한 영어 질문 4단계를 건너뛰고 바로 8자리 인증번호가 뜹니다!)

Copilot이 띄워준 터미널 화면 — 8자리 코드만 브라우저에 입력하면 끝!
🤖 Copilot 실행: gh auth login --hostname github.com --git-protocol https --web ! First copy your one-time code: A1B2-C3D4 👈 1. 화면에 뜬 이 8자리 인증 번호를 눈으로 보거나 복사! Press Enter to open github.com in your browser... 👈 2. 터미널을 클릭하고 Enter 키를 누르면 인터넷 창이 열려요! [웹 브라우저 창] 8자리 코드 입력 후 초록색 [Authorize github] 버튼 클릭! 👈 3. 권한 승인 클릭! ✓ Authentication complete. ✓ Logged in as my-github-id 👈 4. 로그인 대성공! 🎉 (수업 끝날 땐 "깃허브 로그아웃 해줘" 명령!)
교사 메모: Copilot에게 "HTTPS와 웹 브라우저 방식으로 로그인해줘"라고 자연어로 명령하면 `gh auth login -h github.com -p https -w` 옵션을 붙여 실행해 주기 때문에, 학생들이 영어 질문 4개에 일일이 답할 필요 없이 바로 8자리 원타임 코드 화면으로 직행할 수 있습니다!
실습 2단계 (로컬 바이브 코딩) 덕질 · 게임 · K-POP · 스포츠 · 과학 프롬프트

내 컴퓨터 VS Code에서 Copilot과 대화하며 내 즐거움 구현하기 💬

VS Code에서 내 작업 폴더를 열고, Copilot Chat에 아래 탭 중 내가 가장 좋아하는 주제의 프롬프트를 복사해 붙여넣어 보세요! 파일 다운로드 없이 내 폴더에 index.html이 즉시 만들어집니다.

내가 너무 좋아하는 '마인크래프트 건축 & 생존 꿀팁(또는 내가 좋아하는 게임)'을 친구들에게 공유하는 웹사이트를 현재 폴더의 index.html 파일 하나로 만들어줘.
- 디자인 분위기(Vibe): 어두운 다크 모드 배경에 에메랄드빛 네온 포인트가 들어간 게이밍 스타일, 둥근 카드 레이아웃
- 꼭 들어갈 구성:
  1) 상단 히어로 배너: 멋진 제목과 '🎲 랜덤 건축/플레이 미션 뽑기' 버튼 (클릭할 때마다 새로운 미션이 화면에 뜨게 해줘!)
  2) 내가 추천하는 핵심 테마 카드 3개 (중세 성, 해저 기지, 공중 정원 - 이모지와 난이도 별점 표시)
  3) 친구들이 풀어보는 게임 꿀팁 O/X 퀴즈 3문제 (버튼을 누르면 정답 여부와 내 해설이 바로 뜨는 인터랙티브 기능)
- 조건: 외부 이미지 없이 예쁜 이모지와 CSS 그라데이션만 사용하고, 스마트폰에서도 안 깨지게 반응형으로 만들어줘.
내가 덕질하는 최애 K-POP 아이돌과 명곡 플레이리스트를 친구들의 기분에 맞춰 추천해 주는 팬페이지를 현재 폴더의 index.html 파일 하나로 만들어줘.
- 디자인 분위기(Vibe): 파스텔 핑크와 보라색 오로라 그라데이션 배경, 하이틴 다이어리처럼 통통 튀고 세련된 디자인
- 꼭 들어갈 구성:
  1) '오늘 내 기분은?' 선택 버튼 4개 (🔥 텐션 폭발할 때, 🌧️ 감성 충전할 때, ✏️ 집중할 때, 🏃 운동할 때)
  2) 버튼을 클릭하면 그 기분에 딱 맞는 최애곡 제목, 아티스트, 내가 직접 느낀 입덕 포인트 감상평이 카드 애니메이션으로 나타나게 해줘!
  3) 화면 아래에는 '✨ 나만의 가상 응원봉 컬러 바꾸기 & 응원 클릭 카운터' 버튼을 넣어서 누를 때마다 페이지 네온 포인트 색상이 바뀌고 응원 숫자가 올라가는 기능을 넣어줘.
내가 시간 가는 줄 모르고 덕질하는 최애 웹툰/애니메이션/소설 세계관과 캐릭터 매력을 영업하는 소개 사이트를 현재 폴더의 index.html 파일 하나로 만들어줘.
- 디자인 분위기(Vibe): 웹툰·애니 극장판 포스터 같은 감각적인 다크/골드 포인트 테마와 부드러운 카드 전환 효과
- 꼭 들어갈 구성:
  1) 상단에 작품 한 줄 입덕 슬로건과 '💬 오늘의 명대사 자판기' 버튼 (클릭할 때마다 가슴 뛰는 명대사와 캐릭터 이름이 랜덤으로 출력되게 해줘!)
  2) 매력 만점 주요 캐릭터 3명 도감 카드 (성격 키워드 태그, 능력치 바, 내가 뽑은 명장면 설명 포함)
  3) '나와 가장 닮은 캐릭터 찾기' 3문항 미니 성향 테스트 (선택지를 고르면 결과 캐릭터를 추천해 주는 인터랙티브 기능)
내가 좋아하는 스포츠(축구/야구/농구/풋살) 팀과 선수 전술의 매력을 공유하는 웹사이트를 현재 폴더의 index.html 하나로 만들어줘.
- 디자인 분위기(Vibe): 경기장 잔디와 조명을 닮은 에메랄드 그린 & 네이비 조합의 역동적이고 스포티한 에너지
- 꼭 들어갈 구성:
  1) 상단에 멋진 팀 슬로건과 실시간 응원 함성 버튼 (클릭할 때마다 응원 횟수가 올라가고 화면에 ⚽🔥🎉 폭죽 이모지가 터지게 해줘!)
  2) 내가 뽑은 베스트 선수(또는 포지션) 소개 카드 3개와 능력치 막대그래프(스피드, 패스, 결정력, 수비력)
  3) 친구들이 자신의 플레이 스타일을 고르면 가장 잘 맞는 포지션과 추천 선수를 알려주는 미니 전술 테스트
친구들에게 신비로운 우주와 블랙홀, 과학의 즐거움을 쉽고 재미있게 알려주는 인터랙티브 과학 웹페이지를 현재 폴더의 index.html로 만들어줘.
- 디자인 분위기(Vibe): 별이 반짝이는 깊은 우주 밤하늘(다크 네이비) 배경과 사이버틱한 민트색 강조 글씨
- 꼭 들어갈 구성:
  1) 별의 표면 온도를 조절해 보는 인터랙티브 슬라이더 (슬라이더를 움직이면 온도에 따라 별의 색깔이 붉은색→노란색→백색→푸른색으로 실시간 변환되게 해줘!)
  2) 내가 뽑은 가장 신기한 우주 미스터리 카드 3개 (마우스를 올리면 카드가 빛나며 떠오르는 효과)
  3) 3문제짜리 우주 상식 미니 퀴즈와 점수 계산기
💡 프로 바이브 코더의 공식 (4요소): ① 내가 좋아하는 주제 + ② 디자인 분위기(색상·느낌) + ③ 들어갈 내용 3가지 + ④ 클릭·슬라이더 같은 인터랙티브 기능을 함께 말하면 10배 더 멋진 사이트가 탄생합니다!
교사 메모: 학생들이 상단 5개 탭(게임, K-POP, 웹툰·애니 덕질, 스포츠, 과학)을 눌러 예시를 구경하고, [📋 프롬프트 복사] 버튼을 눌러 자기 최애 관심사에 맞게 단어만 살짝 바꿔서 Copilot에 붙여넣어 보게 하세요.

내 컴퓨터에서 즉시 결과를 보고 Copilot에게 실시간 피드백하기 🎨⚡

터미널 명령어 타이핑 대신, Copilot에게 자연어로 커밋 & 푸시 명령하기 🚀

내 컴퓨터에서 완성한 웹사이트를 세상에 공개할 때도 git add, git commit, git push를 직접 타이핑하지 마세요! VS Code Copilot Chat에게 아래 자연어 명령을 복사해 보내고 실행 버튼만 누르면 배포 완료됩니다.

🆕 A. 새 폴더에서 처음 저장소 생성 + 커밋 + 푸시까지 한 방에!

아직 GitHub 저장소를 안 만들었다면 Copilot에게 이렇게 명령하세요:

현재 폴더의 파일들을 Git으로 초기화(main 브랜치)해서 '나만의 첫 바이브 코딩 웹사이트 완성!'이라는 메시지로 커밋해주고, GitHub CLI(gh)를 사용해서 'my-vibe-web'이라는 이름의 공개(public) 저장소를 내 깃허브에 생성하면서 바로 푸시(push)까지 진행해줘!

🤖 Copilot이 자동으로 수행하는 내부 명령어:
git init → git branch -M main → git add . → git commit -m "..." → gh repo create my-vibe-web --public --source=. --remote=origin --push

💾 B. 이미 연결된 폴더에서 수정한 내용을 다시 커밋 + 푸시할 때!

코드를 업그레이드한 뒤 다시 우주 정거장(GitHub)에 올릴 땐 이렇게 명령하세요:

방금 내가 수정한 웹사이트 파일들을 전부 장바구니에 담고(git add), '디자인 및 인터랙티브 기능 업그레이드'라는 메시지로 커밋(commit)한 다음, 내 깃허브 원격 저장소 main 브랜치로 바로 푸시(push)해줘!

🤖 Copilot이 자동으로 수행하는 내부 명령어:
git add . → git commit -m "디자인 및 인터랙티브 기능 업그레이드" → git push origin main

🌐 마지막 스위치: GitHub Pages 인터넷 주소(URL) 켜기도 자연어로 명령하거나 클릭!

방법 1️⃣ Copilot에게 자연어로 스위치 켜달라고 명령하기:

GitHub CLI(gh api)를 사용해서 현재 저장소의 GitHub Pages를 main 브랜치의 루트(/) 경로로 활성화해주고, 내 웹사이트 접속 주소(URL)가 무엇인지 알려줘!

방법 2️⃣ GitHub 웹페이지에서 눈으로 확인하며 켜기:

  1. 내 GitHub 저장소 상단 ⚙️ [Settings] → 왼쪽 [Pages] 클릭!
  2. Branch에서 None을 main으로 바꾸고 [Save] 클릭!
  3. 1~2분 뒤 https://내아이디.github.io/저장소이름/ 주소 탄생 🎉
교사 메모: 학생들이 터미널 명령어를 외우느라 진을 빼는 대신, Copilot Chat에 자연어로 "커밋하고 깃허브에 푸시해줘"라고 지시하고 Copilot이 보여주는 명령어의 의미를 확인한 뒤 [Run in Terminal]을 누르는 최신 에이전트 워크플로우를 익히게 해주세요!
