미래의 성공 공식

내가 즐거워하는 분야를 나누어 가치 만들기

1. 즐거움 찾기 (Passion)

내가 시간 가는 줄 모르게 몰입하고 즐거워하는 분야는 무엇인가요? 게임, 그림, 음악, 과학, 요리 등 무엇이든 좋습니다.

2. 나누어 주기 (Sharing)

혼자만 알고 있는 것이 아니라, 내가 만든 결과물과 지식을 다른 사람들과 나누는 것이 미래 부가가치의 시작입니다.

3. 보상과 가치 (Value)

타인에게 도움이 되고 즐거움을 주는 과정에서 자연스럽게 돈, 명예, 그리고 멋진 커리어가 따라오게 됩니다.

"내가 즐거운 일로 다른 사람을 행복하게 만드는 사람, 그것이 미래 사회가 원하는 인재입니다."

교사 메모: 학생들이 공부나 성적 중심의 사고에서 벗어나 '내가 정말 좋아하는 것'이 무엇인지 짧게 생각해보게 유도하세요.
새로운 시대의 도구

어른들의 방식이 아닌, 전혀 새로운 AI 활용

❌ 과거 어른들의 방식

남들이 시키는 대로 억지로 외우고, 정해진 정답만 맞추는 획일적인 공부와 노력

⭕️ 새로운 AI 시대의 방식

내가 상상하고 기획한 것을 AI(인공지능)와 대화하며 감각적으로 완성하는 바이브 코딩(Vibe Coding)

바이브 코딩이란? 코드를 한 줄씩 타이핑하는 법을 몰라도, AI(ChatGPT, Copilot 등)와 느낌과 분위기(Vibe)를 주고받으며 내가 원하는 프로그램을 순식간에 만들어내는 새로운 방식입니다!
교사 메모: 코딩 문법을 몰라도 아이디어가 중요한 시대가 되었음을 강조해주세요.

핵심 개념 이해하기 (1)

커밋(Commit)이란? 🎮 게임 세이브 포인트!

🕹️ 게임 속 세이브 포인트

게임을 하다가 어려운 보스를 깨거나 중요한 아이템을 얻었을 때, 게임을 안전하게 저장하려고 '세이브(Save)'를 하죠?

💾 깃(Git)의 커밋(Commit)

프로그래밍을 하다가 "여기까지 기능이 아주 잘 작동해!" 하고 내가 만든 변경사항에 '도장을 쾅 찍어서 기록을 남기는 것'이 바로 커밋입니다!

💡 쉬운 비유: "오늘 만든 홈페이지에 예쁜 버튼을 추가했어! 이 상태를 기억해 줘!" 하고 타임캡슐에 담아 이름표를 붙여두는 것과 같아요.
교사 메모: 게임 세이브 개념을 활용하면 중학생들이 커밋의 의미를 직관적으로 이해합니다.
핵심 개념 이해하기 (2)

푸시(Push)란? 🚀 우주 정거장으로 슝 날리기!

🏠 내 방 안의 공책 (로컬 컴퓨터)

내 컴퓨터 안에서 코드를 수정하고 저장하는 것은 온전히 내 방 책상 위에 일기를 쓰는 것과 같아요. 다른 친구들은 볼 수 없죠.

☁️ 인터넷 우주 정거장 (GitHub)

내 컴퓨터에만 있던 커밋(세이브 파일)들을 인터넷 세상의 공유 공간(GitHub 저장소)으로 "슝~" 밀어 올려서(Push) 전 세계 사람들이 볼 수 있게 하는 것입니다!

Commit + Push = 내 컴퓨터에서 세이브(Commit)하고, 인터넷에 업로드(Push)하면 끝!
교사 메모: 로컬과 원격(GitHub)의 개념을 방 안 책상과 우주 정거장 비유로 설명해주세요.
실습 1단계

VS Code에서 GitHub CLI 설치 및 로그인

  1. VS Code 실행하기: 컴퓨터에서 Visual Studio Code를 실행합니다.
  2. GitHub CLI 설치 확인 및 설치: 터미널 창을 열고 `gh --version`을 입력해 봅니다. (설치가 필요하면 안내에 따라 설치)
  3. 로그인하기 (`gh auth login`):
    gh auth login
    화면의 안내에 따라 웹브라우저에서 로그인을 완료하고 인증 코드를 연결합니다.
주의: 학교 계정이나 본인 개인 GitHub 계정으로 안전하게 로그인하세요.
교사 메모: 학생들이 `gh auth login` 명령어 실행 시 브라우저 연동 창에서 막히지 않도록 교사가 순회하며 도와주세요.
실습 2단계

VS Code Copilot 창에서 AI와 대화하며 만들기

🤖 Copilot Chat 열기

VS Code 왼쪽 메뉴나 단축키(Ctrl+I 또는 Cmd+I 등)를 이용해 GitHub Copilot 창을 엽니다.

💬 말로 설명하기 (바이브 코딩)

"내가 좋아하는 음악과 취미를 소개하는 원페이지 웹사이트를 HTML로 예쁘게 만들어줘. 파란색 계열의 세련된 디자인으로 해줘."

AI가 순식간에 코드를 작성해 줍니다. 코드를 직접 짜지 않고 내가 원하는 바이브(느낌)를 대화로 전달하는 것이 핵심입니다!
교사 메모: 학생들이 각자 자신이 좋아하는 주제(게임, 축구, 음악, 그림 등)를 프롬프트에 녹여내도록 격려하세요.
실습 3단계

커밋(Commit)하고 푸시(Push)해서 배포하기

VS Code 터미널 창에 아래 명령어를 차례대로 입력해 봅시다.

# 1. 수정한 파일을 모두 담기 (장바구니에 담기) git add . # 2. 세이브 포인트 도장 쾅 찍기 (커밋) git commit -m "내 멋진 홈페이지 첫 번째 완성!" # 3. 인터넷 우주 정거장으로 슝 날리기 (푸시) git push origin main

이제 GitHub 저장소 설정에서 GitHub Pages를 켜면, 나만의 웹사이트 주소가 뚝딱 만들어집니다!

교사 메모: git 명령어의 의미를 앞서 배운 세이브(Commit)와 우주로 보내기(Push) 비유와 다시 연결해 주세요.
