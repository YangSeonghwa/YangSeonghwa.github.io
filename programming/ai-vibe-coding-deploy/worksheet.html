🚀 3단계: Git 삼총사 비유 퀴즈 & GitHub CLI 배포 실습 기록

🛒 1. 장바구니 담기 (Add)

git add .

새로 만들거나 고친 파일들을 모두 저장 장바구니에 담는 명령어예요.

미니 퀴즈: 명령어 끝의 점(.)은 무슨 뜻일까요?

🎮 2. 게임 세이브 포인트 (Commit)

git commit -m "메시지"

보스전 직전 세이브처럼, 현재 상태에 이름표를 붙여 도장을 쾅 찍는 단계예요.

내가 적은 세이브 메시지:

🛰️ 3. 우주 정거장 발사 (Push)

git push origin main

내 컴퓨터에만 있던 세이브 파일을 인터넷 우주 정거장(GitHub)으로 쏘아 올려요!

미니 퀴즈: 왜 Ctrl+S만 하면 친구가 못 볼까요?
